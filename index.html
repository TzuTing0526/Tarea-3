Conceptos básicos

  • HTML organiza el contenido.
  • CSS define la apariencia.
  • Flexbox distribuye los elementos.
  • Las media queries adaptan el diseño.

Diseño responsivo

Un diseño responsivo cambia su distribución según el espacio disponible. En una computadora puede mostrar columnas y en un teléfono puede apilarlas.

Viewport

Es el área del navegador donde se muestra la página. La etiqueta meta viewport permite ajustar el ancho de diseño al dispositivo.

Media queries

Aplican estilos cuando se cumple una condición. En esta página, cuando el ancho es de 768 px o menos, los elementos se colocan uno debajo del otro.

Flexbox

Se activa con display: flex. La propiedad flex-direction permite organizar los elementos en una fila o en una columna.
